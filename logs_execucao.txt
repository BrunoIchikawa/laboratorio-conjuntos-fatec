>>> CENÁRIO 2: EXEMPLO 2 OFICIAL (CASOS DE BORDA)

[Situação: Conjunto vazio]
  Entrada: A = ∅, B = {1, 2}
  Saída: A ∪ B = {1, 2}; A ∩ B = ∅; A ⊆ B é verdadeiro

[Situação: Conjuntos iguais]
  Entrada: A = {1, 2, 3}, B = {1, 2, 3}
  Saída: A − B = ∅; A Δ B = ∅; A ⊆ B é verdadeiro; A ⊂ B é falso

[Situação: Conjuntos disjuntos]
  Entrada: A = {1, 2}, B = {3, 4}
  Saída: A ∩ B = ∅; A ∪ B = {1, 2, 3, 4}; A Δ B = {1, 2, 3, 4}

[Situação: Um contido no outro]
  Entrada: A = {1, 2}, B = {1, 2, 3}
  Saída: A ⊂ B é verdadeiro; B ⊆ A é falso; B − A = {3}

[Situação: Repetidos na entrada]
  Entrada: A = {1, 2}, B = ∅
  Saída: A = {1, 2}; |A| = 2
